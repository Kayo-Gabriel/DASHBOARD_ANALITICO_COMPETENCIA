A base de dados utilizada deverá ser o AdventureWorks Data Warehouse.

Construir um dashboard utilizando o Power BI;

    os principais insights identificados;
    possíveis tomadas de decisão a partir da análise dos dados;

Realizar a defesa do projeto em sala de aula, com arguição do professor;

Enviar o arquivo do Power BI (.pbix) no AVA.
